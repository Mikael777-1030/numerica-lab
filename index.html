Laboratorio matemático / 01

Integración numérica.

Calcula integrales definidas utilizando métodos numéricos, compara sus aproximaciones y visualiza los puntos empleados en cada procedimiento.

01 / CONFIGURACIÓN

Datos del problema

Define la función o ingresa tus datos.

Operaciones: +, -, *, /, ^ y paréntesis. Funciones: sin, cos, tan, sqrt, abs, exp, log, ln. Constantes: pi, e. Los ángulos se expresan en radianes.

Separa los datos mediante comas o espacios. Los valores de x deben ser crecientes y equidistantes.

02 / REFERENCIA

¿Cómo funciona?

La integración numérica aproxima el área bajo una curva mediante figuras geométricas. El resultado depende de los datos, el paso h y el método seleccionado.

03 / RESULTADOS

Comparación de métodos

Aproximaciones obtenidas para la integral definida.

Configura los datos y pulsa Calcular.
04 / VISUALIZACIÓN

Gráfica de f(x)

Curva evaluada y nodos usados en la aproximación.

Los puntos representan los nodos de integración. La gráfica es orientativa y no representa por sí sola el error numérico.

05 / DATOS CALCULADOS

Tabla de evaluación

Valores de x, f(x) y coeficientes de Simpson.

La tabla aparecerá después del cálculo.
06 / FUNDAMENTO TEÓRICO

Fórmulas utilizadas

Trapecio compuesto
T = h[(f₀ + fₙ)/2 + Σfᵢ]

Suma los valores interiores con peso 1.

Simpson 1/3
S = (h/3)[f₀ + fₙ + 4Σfᵢ impar + 2Σfᵢ par]

Requiere n par.

Simpson 3/8
S = (3h/8)[f₀ + fₙ + 3Σfᵢ + 2Σf₃ₖ]

Los pesos interiores son 3, excepto los índices múltiplos de 3, que tienen peso 2. Requiere que n sea múltiplo de 3.

El error absoluto y porcentual solo pueden calcularse cuando se dispone de un valor de referencia confiable.
